Can one yes/no question match database columns?

We asked Jev, TypeSafe's System One model, "does this column hold the same attribute as that column?" for every column pair in the Valentine schema-matching benchmark (ICDE 2021). We then compared it with the paper's matchers, re-run on this machine, and with Claude Haiku 5.5.

Every dotted number opens its source: a paper table or figure, or the result file, filter, and script that produced it. Headline numbers use test pairs only; the 24 pairs used to tune prompts and baseline settings are excluded.

1 · The question

Schema matching as thousands of yes/no questions

Dataset discovery tools need to know which columns of two tables hold the same thing. Valentine (Koutras et al., ICDE 2021) scores matchers by how well they rank all source×target column pairs. The metric is Recall@ground truth: take the top k pairs, where k is the number of true matches, and count how many are correct.

Jev does not generate text. It takes a state and typed questions and returns one probability per question. A Noul question returns noul, the probability that the answer is yes. We send one request per source column. The state is that column; each target column becomes one Noul. Ranking all pairs by noul gives Valentine's output format.
